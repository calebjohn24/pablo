# C3.22 partial — Root runtime ownership and subagent operations

The core Runtime accepts one admitted RootOwner. That owner supplies the temporary
root identity, shared ledger, cancellation signal and subagent implementation.
An atomic claim prevents reusing the same owner for a second root run. Runtime
checks root UUID/session identity, closes child ownership on preflight errors,
propagates both caller and owner cancellation, and awaits child shutdown before
root tool cleanup and terminal emission. Root terminal accounting reads the shared
ledger after children have joined, while per-agent ledger entries remain distinct.
Normal root completion cancels outstanding children without changing the successful
parent outcome or cancelling the parent token. Error cleanup awaits both child and
root tool ownership rather than skipping one after the other reports failure.

The internal ACP supervisor implements this interface and the ordinary subagent
Tool. Spawn, inspect, wait and stop call its existing admission/registry functions.
The runtime exposes the descriptor only when both prepared parent authority and
runtime tool policy allow it, including immutable host tool-name ceilings. The
ordinary tool path supplies policy decisions, tool-call accounting and a real
execute_tool span. The child inherits that span as its causal parent; the terminal
snapshot now retains its native parent span ID. The same descriptor participates
in model requests and context/compaction byte accounting. Children receive no
subagent tool and cannot acquire a root owner from a derived PreparedRun.

Tool results carry a bounded JSON projection of typed owned state; deserializing
that projection cannot create or reparent an AgentRef. Invalid arguments, unknown
handles and authority failures preserve the supervisor's existing ownership.
Wait timeout leaves child work running; stop awaits cleanup. Raw child transcripts
are not appended to the parent's model history. Existing metadata-only native
trace projection omits subagent result bodies, just as it omits other tool content.
