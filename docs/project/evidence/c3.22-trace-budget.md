# C3.22 follow-up — Shared trace-byte admission

Traced trees install immutable root capture and byte limits before execution or
child registration. The ledger protects the root terminal immediately; each
executed child claims a terminal reservation before its run span. Terminal capacity
covers 12 KiB of metadata/schema/identity plus six times the agent's output-byte
ceiling when capturing content. Actual terminal settlement replaces that allowance
with projected bytes. Untraced trees do not serialize for byte admission.

Native event slots and JSONL bytes now commit under the same ledger mutex after
both checks pass. The bounded size counter uses the writer's borrowed full/redacted
projection outside that mutex and includes newlines. Failed admission consumes
neither resource. Reserved terminals settle after ordinary admission closes;
unused allowances are released, while consumed delivery attempts stay charged
after sink failure because a partial write is possible. Ordinary operation
payloads still must fit available trace space. Terminal admission failure reports
EventDelivery and ends the run span instead of panicking.

JsonlSink::for_tree keeps one writer open through child terminals and closes on
its native root terminal. Supervisor construction installs root trace policy when
the prepared root has a trace path. This is preparation for configured activation;
it does not yet forward original native child events through the supervisor.

Five regressions cover exact full/redacted serialization sizes with escaping and
newline boundaries; oversized content versus redaction; a two-agent race for the
last trace allowance with no partial event/byte charge; terminal protection and
settlement after admission closes; immutable policy, failed child claim and
unused-reservation release; untraced admission without serialization; event-count
denial without byte charge; and failed-sink attempts without refunds. A scoped
runtime tree exhausts child trace space, emits its terminal, then runs and settles
the root using the same writer. Its admitted byte/event totals equal the actual
JSONL output. Both capture modes pass. The initial additional denial fixture used
two event slots, below the runtime's existing four-slot minimum; the fixture was
corrected before final verification.

Final verification: `cargo test --workspace --locked` passed 292 tests with nine
ignored. Explicit `child_admission --include-ignored` passed seven, yielding 293
distinct Rust tests and eight pre-existing ignored cases unrun. Rebuilt Node tests
passed 265; project tests passed 34; TypeScript, all-target warnings-denied Clippy,
formatting/diff checks, and debug/release binary/example builds passed.
