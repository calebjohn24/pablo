# C3.36 footprint title and social card

Date: 2026-09-15

## Change

The homepage browser title, Open Graph metadata and Twitter card metadata now use `Pablo — A 15× smaller harness for your agents`. Their description uses `A lightweight agentic harness for non-coding knowledge work, built in Rust.`

The 1200×630 Open Graph image uses the same headline and subheader. Its resource panel anchors the 15× position to peak process-tree memory against Claude Code and retains the measured Pablo, Pi, Codex and Claude Code values. The SVG is the editable source; `og.png` is its rasterized public artifact.

## Landing simplification

The benchmark graphic now appears once in the primary hero. The former full-width duplicate was replaced with an interoperability section that explains how the single native Rust executable hosts ACP, connects MCP tool servers, delegates through A2A and loads portable Agent Skills. Each protocol card links to its detailed guide.

The landing-page prerelease warning was removed; the detailed limitations remain on the dedicated release-status and installation pages. The final call to action was shortened to `Try Pablo today`, followed by the integration-guide link.
