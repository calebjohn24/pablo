# C3.36 one-line installer and mobile alignment

Date: 2026-09-14

## Scope

The public install path is now one copyable command:

```sh
curl -fsSL https://runpablo.pages.dev/install.sh | sh
```

The script itself pins `v0.0.1` and defaults to `$HOME/.local`, while retaining explicit `--version` and `--prefix` overrides. It still verifies the archive checksum and executable version, refuses unsafe collisions, and keeps receipt-verified update and removal behavior.

The landing-page hero label, heading, description, buttons and terminal content are left aligned at the 390 px mobile breakpoint. The public benchmark graphic and caption replace the “Exploratory single-seed pilot” footer with the factual “Six-task local comparison” label; historical project evidence remains unchanged.

The `v0.0.1` archives remain private until native acceptance completes. This change makes the final install command usable once those exact accepted archives are published; it does not publish or rebuild a candidate.
