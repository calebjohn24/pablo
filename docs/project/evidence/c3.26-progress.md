# C3.26 progress: bounded public Agent Cards

C3.26 remains in progress. This increment adds core Agent Card validation and public HTTP retrieval; it does not satisfy R01 or expose remote task delegation.

A2A 1.0 and independent Python SDK 1.0.2 are pinned in `tests/fixtures/a2a/lock.json`. SDK-generated card/wire vectors and the SDK HTTP card route establish the selected JSONRPC profile. `docs/project/contracts/c3-a2a.md` describes the current subset and outstanding work.

Validation checks exact host-selected HTTPS interfaces, required extensions, host-selected bearer scheme declarations, malformed security requirements and the 64 KiB card limit. Fetching rejects redirects and non-JSON responses, bounds response bytes and time, and sends no credential. Raw card SHA-256 identifies untrusted metadata; it is not remote authentication.

Verification on the current source:
- `cargo test --locked -p pablo-core --test a2a_cards -- --include-ignored`: six passed, including the independent SDK HTTP server, joined cleanup and no task/credential submission.
- `cargo clippy --workspace --all-targets --locked -- -D warnings`: passed.
- `cargo fmt --all -- --check` and `git diff --check`: passed.

Explicit deadline/cancellation prechecks fixed this; the existing no-connection assertion then passed. These failures were not counted as passing acceptance.
