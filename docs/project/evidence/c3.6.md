# C3.6 acceptance — OpenRouter streamed tool calls

C3.6 implements the [OpenRouter contract](../contracts/c3-openrouter.md) and P02 through the existing core provider lifecycle. CLI, ACP and configured deployments select the OpenRouter adapter with default `z-ai/glm-5.3-flash`; Vercel remains the default gateway with `zai/glm-5.3-flash`. Schema v1/revision c3.5 is unchanged: these provider fields already existed. No paid provider call was made; C3.7 owns live acceptance.

## Acceptance observations

| Requirement | Executed evidence |
| --- | --- |
| Real model/tool/model path | P02 runs legacy and configured OpenRouter through CLI and two successive ACP tasks per process: six completed file-read tasks and twelve HTTP requests. A Unicode filename/content and seven-byte HTTP writes fragment UTF-8, CRLF and SSE JSON independently of fragmented tool names/arguments. The next model request contains the actual filesystem result and original call ID. Optional null tool identity/name/argument placeholders are accepted for OpenRouter without changing Vercel handling. |
| Prefix, identity and reuse | Every request preserves serialized instruction/user and tool-definition prefixes. Provider requests use the selected GLM model, streaming, sequential tools and the requested output-token bound, omitting the deprecated OpenRouter usage flag. Native model starts report OpenRouter and the exact model; each completed task has two model finishes and one run finish. Both successive ACP tasks reuse one actual HTTP connection, including configured resource reuse. |
| Usage/cache/cost | Final accounting choices may repeat the terminal reason without creating another finish. Six successful tasks each settle two calls with exact token/cache sums and one rounded charge per call, ignoring upstream-provider cost. Separate cases preserve absent/null fields as unknown and explicit zero as zero; a raw decimal at the u64 micro-USD maximum and a token count above JavaScript's exact-number range survive in decimal-string task accounting. The native decimal test covers exponent syntax, fractional micro-USD, long/negative/overflowing values and duplicate cost. |
| Safe failures | Twenty-three cases execute through both CLI and ACP: HTTP rejection/throttling/redirect, wrong content type, disconnect, midstream error, invalid JSON/UTF-8, missing DONE, duplicate ordinary finish/usage/counter/cost, post-finish content, inconsistent repeated finish, negative usage/cost, invalid cache details, overflowing cost, bad tool index/name/arguments and a frame over 32 MiB. Each has the expected closed failure/delivery code, one terminal outcome and no tool dispatch. There are no retries or requests to the redirect receiver. Existing shared SSE response/frame-count bounds remain covered by core tests. |
| Cancellation and subsequent use | CLI SIGINT and ACP cancellation interrupt the second model stream after a completed file read. The peer observes each socket closed; native records retain the first call's usage while aggregate usage/cost remain unknown because the second call was delivered without accounting. There is no invented zero/refund. A subsequent ACP task completes cleanly in the same process. |
| Private credential resolution | Rust proves ordered OpenRouter environment/file/host lookup and exact consumer/destination exposure; invalid present values prevent fallback. CLI/ACP synthetic dotenv failures cannot fall back to Vercel keys and create no trace or network effect. Configured invalid credentials reject at startup. The local fixture constructor takes no real-key argument; all fixture HTTP requests carry only its fixed synthetic token. |
| All serialized surfaces | Successful task stdout, ACP wire output, diagnostics, native traces, model requests and actual OTLP Protobuf payloads omit gateway and reasoning sentinels. Content-disabled native/OTLP data omit the filesystem marker. A separate actual shell `env` round trip with content capture proves neither OpenRouter nor Vercel keys enter child environment, captured traces or task output. |
| Compatibility and runnable commands | P01 still compares default/explicit Vercel CLI/ACP requests; unavailable Open Responses rejects before effects. The [README](../../../README.md#run-a-real-task) has copyable CLI and ACP OpenRouter commands. Existing filesystem, shell policy, deployment, ACP and telemetry regression gates pass. Unlimited default filesystem work limits remain unchanged. |

OpenRouter reporting does not attest hard aggregate token/cost ceilings. Currency conversion uses the original decimal token and integer arithmetic, rounding positive fractional micro-USD upward once per call; the granularity adjustment is less than one micro-USD per call. Provider reasoning/opaque continuation data is not forwarded or exposed; this slice covers text and built-in tool calls, not opaque reasoning continuation or remote accounting reconciliation.

## Performance

[Measurement summaries](c3.6-measurements.json) retain source/binary/harness hashes, methods and distributions for six lifecycle and three configured filesystem variants. Each used 30 samples after five warmups, sequentially without overlapping builds/tests, on native macOS arm64 with Node 24.11.0 and Rust 1.98.1. The frozen C3.5 executable hash matches its checked-in report. The fixed local gateway workload deliberately omits usage; accounting-rich behavior is covered by P02, while these timings compare local lifecycle/transport overhead without remote model or billing latency.

Release size changed from 11,214,592 to 11,231,136 bytes (+16,544, about 0.15%).

| C3.6 Vercel legacy | 14.251 | 7.921 | 10.127 | 7.680 | 8288 / 14272 |

Vercel medians remain close to the matched baseline. Tails vary by path: legacy ACP p95 rose 11.324 → 14.834 ms while configured ACP p95 fell 19.762 → 14.215 ms. These distributions do not establish a universal speedup or hard latency bound. Configured filesystem tool p50 milliseconds, C3.5 Vercel → C3.6 Vercel / OpenRouter: read 0.142 → 0.140 / 0.142; list 0.999 → 0.993 / 1.013; search 2.105 → 2.122 / 2.086; replace 0.521 → 0.502 / 0.501; edit 0.466 → 0.424 / 0.438. No provisional performance ceiling was invented.
