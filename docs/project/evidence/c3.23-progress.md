# C3.23 implementation and initial verification

The supervisor now owns a bounded FuturesUnordered set of at most two executions,
pops pending jobs FIFO, and retains/polls all active executions through cancellation
and joined cleanup before closing root updates. The root resource ledger uses the
existing two-child constant; each child still owns one active slot. No worker is
detached or aborted to implement concurrency.

A03 provider barriers prove two simultaneous model operations. Independent stop or
failure releases a slot for queued work while the sibling remains observable and
runnable; wait-any/all retain selected ordering. A configured root-cancellation
case joins both active children before root terminal and never starts the queued
third. The supervisor stress case fills two active plus fourteen pending slots,
rejects a seventeenth without mutation, then settles all sixteen on cancellation.

Existing one-slot assertions initially failed as expected when the second slot
became available. They now occupy one slot before racing for the remaining slot,
or observe both active requests before cancellation/deadline assertions. Races
cover root plus two children for model/tool allowances and separate token/cost
liability; process/MCP final-slot races and three protected terminal trace capacity
are also explicit. Prior uncertainty/refund and authority tests remain applicable.

Workspace Rust passed 305; explicit factory and child-admission tests add three
otherwise ignored cases for 308 distinct passing Rust tests. Clippy and builds
passed. The first full Node run passed 273/274: F03 primary-to-third observed three
notification callbacks instead of four. The focused fallback suite passed 18/18
without changing fallback code. This matches the pre-existing C3.15/C3.17 race and
remains C3.33 work; a passing rerun cannot establish resolution. After adding the
configured two-active-root-cancel case, final compatibility and performance checks
are recorded separately. This progress record does not claim checkpoint completion.
