# C3.36 E2B one-line installer check

Date: 2026-09-15

## Result

The exact public command does not currently install Pablo:

```sh
curl -fsSL https://runpablo.pages.dev/install.sh | sh
```

In a fresh unprivileged E2B Debian 12 x86_64 sandbox, the script itself downloaded successfully and matched the reviewed repository source byte for byte. It then failed with exit code 1 because the versioned Linux archive route returned HTTP 404. No binary or installer receipt was left behind.

The failure is in distribution availability, not the pipe or installer behavior. The same deployed script, still invoked through `curl | sh`, installed successfully after the exact frozen `v0.0.1` Linux x86_64 archive and checksum were transferred privately into the sandbox. Default version and prefix selection produced `/home/user/.local/bin/pablo`; the installed binary matched the frozen candidate SHA-256, reported `pablo 0.0.1`, and printed `Hello from pablo.` from the offline demo. Piped removal deleted the owned binary and receipt.

## Environment and identity

- E2B SDK: 2.49.1.
- Guest: Debian GNU/Linux 12, Linux x86_64, glibc 2.36.
- User: unprivileged UID/GID 1000 with home `/home/user`.
- Sandbox: 2 vCPUs and 512 MiB memory.
- Deployed installer SHA-256: `757da21421b9c78d9994171808268d166bd5e53fa0a2b71060ab3c0cd83d171b`.
- Frozen archive SHA-256: `2fc82bdd63eb15c96e24b7792e92a458432e0cb3ab64cc399cf8b75d32fa1b93`.
- Installed binary SHA-256: `b31d3674cedec9dc0f99d3058570754bd253528d66171cc8737862453391070a`.

The E2B credential was supplied to the local SDK process through non-echoed standard input. It was not passed to or present inside the sandbox, recorded in output, or written to repository files. The sandbox was killed in a `finally` path, and a post-run E2B listing found no running or paused sandbox for this workload.

## Release boundary

The public one-line install remains unavailable until the accepted four-platform archive set is published to the R2-backed `/releases/v0.0.1/` route. This test did not publish or rebuild the candidate.
