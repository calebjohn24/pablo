# C3.22 partial — Root-owned child supervision

An internal root supervisor now owns temporary child handles, its FIFO pending
queue, independent cancellation tokens, bounded typed update delivery and joined
shutdown. Spawn projects authority from the fixed prepared parent and admitted
parent tool catalog, then atomically registers identity and pending/input/result
capacity before returning a queued handle. A single driver promotes jobs to one
active slot and reserves the child's context ceiling. It binds the existing typed
ACP dispatcher using the promoted lease, without registering a second child.

Inspect returns owned state, per-child accounting and a bounded terminal snapshot.
Wait-any/all validate ownership and unique selections, preserve requested ordering,
return all settled selections and remaining handles, and never cancel work on
wait timeout. Stop is idempotent for settled children, removes queued work without
a provider call, or cancels active work and waits for settlement after dispatcher
close has joined its worker. Cancelling one child does not cancel its sibling or
root. Root cancellation/deadline and a lost update receiver drain the queue and
join active work. Close retains its join and result across cancelled/repeated
callers; normal close does not cancel the parent token.

Agent lifecycle transitions preserve immutable ownership, bind one ACP session,
and prohibit reopening settled children. A session admitted during stop retains
its identity without restarting the child. Scoped runtime cancellation now checks the shared root deadline before choosing
its native outcome. The supervisor does not relabel a cancelled native terminal
as timed out. A focused test verifies native/returned deadline agreement.

A promoted lease is checked against the
same ledger and agent. Pure capacity reductions remain legal after admission
closes, so joined execution can release active/context capacity while retaining
its result allocation. Snapshots exceeding the 64 KiB serialized result bound
return an output-limit outcome instead of truncating successful structured output.

The worker saves a child-only native terminal receipt before delivery. Consequently,
a stalled or failed ACP acknowledgement cannot erase the settled outcome, accounting,
validation/repair metadata or available trace identity. Ordinary ACP does not allocate
this receipt. The supervisor retains ownership, handles and results outside model
history; compaction does not own their lifetime.

Remaining C3.22 acceptance:

The supervisor is internal, and delegation remains disabled. Install the ordinary
policy-checked/accounted subagent tool and equivalent host calls into the root
runtime. Root terminal emission must await supervisor close even on normal completion;
root cancellation must also stop ledger admission and aggregate accounting must
include child work once. Add native/ACP/OTel immutable agent attribution and the
root multiplex sequence; the current typed update wrapper alone is not that proof.
Attach shared process/MCP permits and root resident-context growth to real ownership,
and reserve cumulative root event/trace capacity, including terminal space.

Keep the current single driver at one active child for C3.22; two concurrent drivers
and A03 belong to C3.23. Preserve FIFO leases and cancellation-safe joins during
that transition. A02 and actual integrated-child performance remain required before
checkpoint completion and PR merge. Preserve GLM defaults, unlimited filesystem
work, compaction details and the C3.33 F03 / C3.39 performance follow-ups.
