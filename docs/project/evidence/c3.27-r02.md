# C3.27 — R02 supervised remote tasks

R02 passes. Host and model delegation now admit configured A2A tasks into the same
root supervisor as temporary local children. Immediate Message, terminal Task and
streamed status/Artifact results preserve the peer's IDs separately from local
agent/run/session identity. C3.28 retains adverse cancellation, lost-stream,
input-required and Collector/outage acceptance.

## Implementation and acceptance

- `PendingRemote` creates queued ownership without network or credential lookup.
  Promotion reserves active/context/result capacity before retrieving the card on
  that same identity. Local and remote jobs share two active/fourteen queued/sixteen
  total capacity. Queued cancellation submits neither a card nor a task request.
- `spawn_remote.remote_request` accepts only the selected name, explicit Parts,
  output modes and optional stream/duration. Host and model paths use the same
  admission method. No RunSpec, transcript, tool catalog or credential transfers.
  With no configured remote, the model tool schema retains its local-only shape.
- The bounded lifecycle and TaskClient from the earlier increments feed acknowledged
  native start/update/finish events. Metadata-only traces exclude content, filenames
  and private root input. ACP emits standard attributed tool-call updates in the
  root session. The local span is causally parented by delegation; actual remote
  span propagation remains R03.
- Typed results retain text/data/inline files/inert URLs and original IDs. Logical
  output bytes also obey the parent's ceiling. A four-byte parent rejects the
  five-byte artifact without retaining it as a successful result. No remote URL is
  fetched or filename interpreted as a local path.
- Optional decimal-string usage claims are retained separately from local
  accounting, including exact values above 2^53. Invalid/overflow/unknown fields
  reject. The fixture reports twenty tokens and forty-two microUSD while its
  remote child consumes zero local model/tool calls or model tokens. Model-facing
  delegation itself retains ordinary root tool/model accounting.
- Basic assigned-task cancellation joins one exchange and retains a separate peer
  receipt. Root shutdown drains the native consumer and releases active/pending
  resources. A canceled receipt does not prove remote work stopped or rolled back.

warmups, source/binary identity checks and identical configured/filesystem harness
code. Every build/test/check process terminated before measurements; all workloads
ran sequentially and their owned peers were joined.

Baseline/current configured medians: core 9.120/9.381 ms, initialize
10.631/10.605 ms, fresh ACP prompt 15.575/16.008 ms, warm ACP prompt
14.780/14.284 ms, idle RSS 17,104/17,376 KiB. The release grows by 414,784 bytes
(2.87%) as the previously unused task transport becomes executable code.

list 2.451/2.748, search 3.083/3.225, replace 2.384/2.594, edit 1.323/1.559.

list 3.052/2.470, search 3.424/3.051, replace 2.646/2.471, edit 1.515/1.421.

make no causal speedup or regression claim.

`node scripts/measure-a2a.ts` establishes the complete supervised workload baseline:
fresh ACP process/session/prompt and joined shutdown, three mock model requests,
two delegation tool calls, card GET, streamed SDK artifact and metadata trace.
Median 17.570 ms, p95 19.271 ms. SDK/gateway startup is excluded. This includes
more than supervisor cost; it is not a standalone overhead delta or live network,
