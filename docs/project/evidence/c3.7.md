# C3.7 acceptance — live OpenRouter

P03 passed on 2026-09-10 through the release CLI and the official TypeScript ACP client using OpenRouter `z-ai/glm-5.3-flash`. Each task read freshly generated local evidence through exactly one allowed `fs.read` call and returned the exact file contents. Both tasks completed two real model calls with one terminal outcome. ACP streamed the same answer and delivered the exact filesystem result.

## Reproduce

Supply `OPENROUTER_API_KEY` privately in the ignored root `.env`, then run:

```sh
cargo build --release --locked -p pablo
node scripts/smoke-live-openrouter.ts target/release/pablo .env
```

This is an explicit paid check; ordinary tests remain offline. The second argument selects only the supplied dotenv file, bypassing any stale ambient key. Omitting it permits the OpenRouter environment variable before root `.env`. The harness passes credential references; only the executable opens and resolves them. No credential file was printed, sourced, copied into records, or read by the harness.

Each surface receives a fresh temporary workspace and unseen marker, a policy allowing only `fs.read`, disabled shell, a two-model-call/one-tool-call cap, 4,096 requested output tokens per call, and a 90-second run deadline. Child watchdogs terminate at 100 seconds and kill at 110 seconds. Fixtures and telemetry environment overrides are removed before launch. Owned processes exited normally and all C3.7 task workspaces were removed, including failed attempts. Raw metadata traces remain ignored under `.pablo/live/`; only sanitized summaries are checked in.
