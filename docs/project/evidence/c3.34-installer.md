## Installer contract

`install.sh` is a POSIX shell installer with no Node or Python dependency. It requires an exact release tag and absolute prefix, detects the selected four-target macOS/Linux architecture name, downloads the matching GitHub archive and per-archive SHA-256 file, verifies the checksum before extraction, extracts only the expected executable member and executes its version check before installation.

The install target is `$PREFIX/bin/pablo`. A command visible outside the selected prefix rejects, and an existing target rejects unless `--replace` is explicit. Replacement accepts only a regular non-symlink target and stages the new executable in the destination directory. A versioned receipt under `$PREFIX/share/pablo` records the installed target and binary hash. `--remove` verifies that receipt and current binary hash before removal, rejecting a changed executable and preserving unrelated prefix files. The script never calls `sudo` or a package manager.

Local `--archive` and `--checksum` inputs exercise candidate artifacts without network access. The website build publishes the exact repository script at `/install.sh` with a short cache lifetime and plain-text content type. The GitHub documentation workflow runs the offline installer tests before the site build.
