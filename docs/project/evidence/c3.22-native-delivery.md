# C3.22 follow-up — Original native child delivery

Supervised children now use a native output mode on the existing admitted typed
ACP dispatcher. Inputs, initialize/session/prompt handling, cancellation and owned
worker settlement are shared with typed and stdio dispatch. Output selects the
original RunEvent channel before EventStream coalescing or ACP notification
projection. The supervisor's bounded update stream carries that original record
and its immutable identity, plus the routing handle and consumption acknowledgement.
No child transcript is added to the root model context.

The worker retains its existing eight-event queue and 32 MiB record bound. Native
delivery keeps one update awaiting consumption through a one-slot channel to the
supervisor and its existing eight-slot root update channel. It uses the existing
30-second delivery deadline. Receiver loss wakes both idle and unacknowledged
forwarding; errors invoke existing prompt cancellation, event-queue closure and
joined cleanup. An acknowledged terminal completes delivery even if the consumer
immediately closes. PendingPrompt still awaits worker settlement, and supervisor
close still joins the dispatcher before releasing admitted child resources.

Three new tests prove exact original record equality and uncoalesced deltas through
the pre-projection path, consumption acknowledgement, idle/in-flight receiver
loss, and successful close immediately after terminal acknowledgement. A real
supervised child with a local HTTP provider emits run/model start, three distinct
deltas, model finish and run finish. All seven original sequence numbers,
timestamps, agent/root/session IDs, causal spawn/run/model span relationships,
route metadata and terminal accounting survive; snapshot and ledger agree. Existing
FIFO, cancellation, lost receiver, deadline and abandoned close-caller tests now
exercise this native path.

During development, fixture assertions were corrected to match native contracts:
accounting appears on the terminal and protocol-specific model_profile is optional;
routed metadata is asserted on model start/finish. Cancellation can now happen
before the first provider response is read, so the established joined-connection
assertion accepts EOF or TCP reset. All other socket outcomes remain failures.
Review also fixed a race between terminal acknowledgement and receiver closure.
The native payload fields remain gated from production use until root-consumer
factory wiring lands; Clippy's temporary dead-code allowance documents that boundary.

Final verification: workspace Rust tests passed 295 with nine ignored; explicit
child_admission passed seven (296 distinct Rust tests including one otherwise
ignored case; eight pre-existing ignored cases remain unrun). Rebuilt Node tests
passed 265; project tests passed 34. TypeScript, final all-target warnings-denied
Clippy, formatting/diff and debug/release binary/example builds passed.

tests/builds, with 30 samples and five warm-ups. Baseline/current medians in ms:
core 9.013/8.642; ACP initialization 10.782/10.111; fresh prompt 16.081/14.709;
warm prompt 15.181/9.146. Warm RSS was 18,304/18,304 KiB; release size was
13,795,856/14,012,464 bytes (+1.57%). Filesystem prompt medians for
read/list/search/replace/edit were 1.567/1.466, 2.109/2.102, 2.903/3.161,
2.243/2.453 and 1.289/1.365 ms. The results are mixed; the large warm-prompt
difference is an observation, not a causal improvement claim. These unscoped
