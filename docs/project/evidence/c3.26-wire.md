# C3.26 increment: bounded wire codecs and independent SDK dispatcher

C3.26 remains in progress. This increment implements text/data wire codecs and conformance fixtures; required file Parts and trace-extension metadata remain unfinished. It is not production supervised remote execution or full R01 acceptance.

`a2a::wire` encodes SendMessage/SendStreamingMessage and CancelTask using the pinned v1.0 PascalCase methods and protobuf JSON fields. Requests carry only explicit input and ask for historyLength zero. Typed response decoding distinguishes send result unions, SSE event unions and the direct Task returned by CancelTask. It preserves message/context/task/artifact IDs, task dispositions and append/lastChunk flags; text and structured JSON null are supported. Known duplicate fields, ambiguous unions, mismatched envelope identity/version, legacy role/state aliases, excess bytes/counts and unrequested history reject. Numeric remote errors stay distinct from local failures without promoting remote message/data into diagnostics.

Bounds and implementation limits are in [the contract](../contracts/c3-a2a.md#current-bounded-wire-codec). Codec byte/count enforcement is implemented. Transport framing, wall/idle/cleanup timers and supervisor accounting remain C3.27/C3.28; constants alone are not evidence of those runtime guarantees.

The official Python SDK JSONRPC/SSE dispatcher accepts Pablo-encoded requests and produces immediate Message, terminal Task, streaming status/artifact/task, successful canceled Task and task-not-found replies decoded by Pablo. An unsupported version returns -32009 without invoking the handler. The fixture asserts only selected synthetic input, empty metadata and explicit zero history; it observes five handler calls and joins its server. SDK protobuf-generated vectors pin request/wrapper shapes, including direct CancelTask results. This is protocol conformance, not a real remote-work cancellation proof.
