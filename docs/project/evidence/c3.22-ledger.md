# C3.22 partial — Atomic root/agent accounting foundation

This is partial implementation evidence, not A02 acceptance. Delegation remains
unsupported and no child is launched by these changes.

`children::ledger::RootLedger` owns one mutex-protected root accounting record,
per-agent counters and at most three in-flight model reservations. Child registration
checks immutable root/parent/session ownership, total registered-child capacity and
narrowed model/tool/token/cost ceilings. This registers counters only: supervisor
capacity and full authority admission must precede registration in the final path.

Model admission checks and commits root plus local call counts and attested token/
cost reservations atomically. All checks run against temporary copies before commit,
so a failed cost check cannot consume model or token allowance. Tool count admission
is also atomic. Owned, non-cloneable model reservations settle once. Abandonment
records unknown actual usage and retains possible liability, while proven not-sent
settlement refunds liability without refunding the attempt count.

The implementation reuses existing `task::Ledger` reserve/settle behavior through a
new bounds constructor, rather than inventing different child accounting rules.
This preserves unknown usage, conservative uncertain charges and bound-violation
semantics. No runtime model/tool admission site is wired to RootLedger yet; current
single-agent execution still uses its existing local accounting path.

Checks actually run:

- `cargo test --locked -p pablo-core --lib children::ledger`: 4 passed. Barrier races
  prove only one root/child caller spends the final model/tool allowance. Other tests
  cover atomic rollback of denied multi-resource admission, unknown liability,
  proven-not-sent refunds, accounting-bound violation, closed admission and rejected
  foreign/widened registration.
- `cargo test --locked -p pablo-core --test accounting`: 9 passed.
- `cargo check --locked -p pablo-core`, workspace all-target Clippy with warnings
  denied, formatting and diff checks passed.
