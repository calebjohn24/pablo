## Result and authorized scope

After C1.2, the user asked to test the agent as an end user. C1.2a brings forward one real terminal task through the existing Rust runtime. The user then explicitly requested direct HTTP instead of a Vercel SDK. `pablo run "TASK"` now uses a direct HTTP/SSE adapter with the general-purpose `reqwest` client; no Vercel SDK was added. ACP and formal live ACP acceptance remain separate checkpoints.

The CLI loads the existing gateway credential privately, enables the bounded shell capability by default, streams model answers, reports shell activity, and awaits cleanup on Ctrl-C. It accepts workspace/model/credential-file/deadline overrides, text-only mode, and optional private traces. Each invocation is a fresh bounded task. See [the gateway contract](../../gateway.md) and [README](../../../README.md).

## Findings resolved

The first integrated test run exposed macOS inheriting a nonblocking flag on accepted fixture sockets; the stalled-response fixture read returned `WouldBlock`. The fixture now explicitly sets accepted sockets to blocking mode with bounded read/write timeouts. The production transport was not responsible for that failure. An unused development helper/import was also removed before final linting.

The first attempted live smoke stopped locally before sending any request because the existing `.env` uses `VERCEL_AI_GATEWAY`, while the original plan named `AI_GATEWAY_API_KEY`. The CLI now supports the existing name as an alias, preserving the file. A synthetic configuration test checks alias selection without sending credentials. The subsequent live smoke passed.

## Handoff

C1.2a is complete. C1.3 is ready: add pinned official ACP Rust/TypeScript SDKs, `pablo acp --stdio`, and the reference client. Reuse `GatewayProvider`, the loopback fixture override, the existing lifecycle, and cancellation token. Add ACP ordering, bounded queues, disconnect/slow-consumer cleanup, and protocol-only stdout. C1.4 still needs live acceptance through that ACP boundary; C1.5–C1.6 retain Collector/platform/full-cycle gates.

The preview does not add persistent chat, a TUI, a sandbox, full model portability, cost-ledger enforcement, or networking telemetry export. The CLI's inline terminal/trace sink limitation and host containment responsibilities remain documented. No ACP, Linux, or Collector execution is claimed here.
