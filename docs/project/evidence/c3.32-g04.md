## Delivered behavior

- Versioned [base, production and development presets](../../../presets/v1/README.md)
  configure every implemented subsystem, preserve the selected OpenRouter/Vercel
  models and unlimited model/tool/filesystem-work defaults, and keep credentials
  as external references. Production adds immutable local write, command, MCP-tool
  and trace-content ceilings. Development enables writes. The optional observed
  profile configures explicit OTLP export.
- The [manifest](../../../presets/v1/manifest.json) records six bundle-file digests
  and six configuration/input identities (three entries, default/observed profiles).
  `scripts/preset-manifest.mjs` verifies them offline. Rendering preserves effective
  configuration identity while changing composition/input identity. Asset bindings
  remain portable and separate from physical workspace identity.
- The [G04 tests](../../../tests/presets.test.ts) run 27 task cases: three presets
  × CLI/ACP/direct Rust embedding × full success/shell denial/filesystem write.
  The full task actually performs an eligible OpenRouter→Vercel fallback, a real
  filesystem read, one forced context compaction with exact task facts retained,
  a selected Skill resource read, HTTP MCP, one local child and one streamed A2A
  child, an allowed shell command, and validated final output. Root accounting
  includes every fallback, summary and local-child model request exactly once.
- Separate denied commands leave their marker intact with no shell execution;
  base/production reject filesystem writes while development commits them.
  Native root sequences are contiguous, each child and root settles once, remote
  model accounting stays zero, and all nine MCP sessions per preset send DELETE.
  Independent pinned MCP/A2A SDK peers are joined after each fixture.
- Every task exports real OTLP through the observed profile, including runs with
  ambient OTel disablement/endpoint/header noise. The test instantiates only the
  documented collector endpoint in an operator copy before rendering; explicit
  host-only loopback transport injections supply synthetic provider/MCP/A2A peers.
  Native traces and exported spans exclude task content and credential bytes.
- The embedding [reference host](../../../crates/pablo/examples/preset_host.rs)
  calls `Runtime` directly with the existing root factory/ledger and native sink;
  it does not spawn the CLI. Explicit source-module paths let that example reuse
  the same host implementation, including nested test modules. Cancellation joins
  the owned run before telemetry shutdown. These host modules are not advertised
  as a new published crate API.
- The [option inventory](../contracts/c3-deployment-options.md) reconciles all 18
  implemented option roots and CLI mappings, dynamic callbacks/secrets/platform
  inputs, fixed child/transport/TUI/doctor invariants, and still-unsupported future
  compatibility keys. Unknown and reserved settings reject explicitly. The bundle
  documents migration, bindings, external-service trust, and the remaining native
  packaging gates. Historical C3.1 fixtures remain intact.
