# C3.36 — E2B Pablo/Vercel knowledge-work benchmark

At the user's request, the frozen `v0.0.1` Linux x86_64 release candidate ran the six-family `knowledge-work-v1.1` task benchmark in an unprivileged E2B sandbox through Vercel AI Gateway. Only the new `pablo-vercel` profile ran. It requested Vercel's `zai/glm-5.3-flash` with provider-default reasoning, seed 42, one attempt per task, a 180-second per-attempt timeout, no retries and no overlapping build, test or benchmark work.

[Sanitized measurements](c3.36-e2b-vercel-knowledge-measurements.json)

## Result

All six attempts completed and the provider reported the requested model on every attempt. Pablo answered all 25 factual checks correctly. Four of six tasks also passed the legacy exact citation diagnostic. Vendor selection had zero exact citation-set credit and meeting handoff had 60%; both remained factually complete. Citation scoring requires the benchmark's exact minimal filename sets and does not grade prose quality.

## Harness changes and preflight findings

The runner now exposes an explicit `pablo-vercel` profile and forwards only the two supported Vercel credential environment names. Its command is the same bounded Pablo task path with `--provider vercel --model zai/glm-5.3-flash`. The output setup now creates missing parent directories while retaining refusal to overwrite an existing result directory. The adapter and nested-output behavior are covered by the existing 17-test offline benchmark suite.

Two fresh E2B preflights stopped before model delivery. The base template's Node 20.9.0 lacks `node:util.parseEnv`, so the final sandbox installed the repository-pinned Node 24.20.0. The next preflight exposed the missing nested output parent, which was fixed and tested. Both preflight sandboxes were killed; neither is included in the six measured attempts. A partially completed local multi-system run was also interrupted when the user narrowed the request to Pablo on E2B, and it is excluded from this result.

## Verification

- `node --test --test-concurrency=1 scripts/knowledge-work/benchmark.test.mjs`: 17 passed after the Vercel profile and nested-output change.

- The live runner produced exactly six rows, six completed statuses, 25/25 factual checks, matching reported model identities, no interruption and no credential match across its captured/downloaded report surfaces.
- The benchmark lock and owned processes were absent locally after completion; the E2B account reported zero running or paused Pablo sandboxes.
