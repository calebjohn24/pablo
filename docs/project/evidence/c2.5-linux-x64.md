## Environment and provenance

The private repository's GitHub-hosted `ubuntu-24.04` runner executed native x86_64 binaries, with no architecture emulation. This is an Azure VM, not bare-metal performance evidence: Ubuntu 24.04.5, kernel `6.17.0-1022-azure`, AMD EPYC 9V74, two logical CPUs, 8,323,973,120 bytes of memory, runner image `20260907.300.1`. The workflow asserted Linux, x86_64 kernel and Rust host, Node x64 and non-root UID 1001. Permission fixtures therefore exercised actual denied access. Rust was 1.98.1 and Node matched `.nvmrc` at 24.20.0.

The [workflow](../../../.github/workflows/c2-acceptance.yml) pins third-party actions by commit, uses a read-only repository token, disables persisted checkout credentials and requires no provider secrets. Tests use synthetic local inputs. Collector and native traces stay outside uploaded reports. The exact [aggregate reports](c2.5-linux-x64-measurements.json) retain workflow results, platform, build and source identities. Raw CI logs and measurement arrays remain ignored local artifacts; the workflow's measurement artifact expires after 14 days.

## Matched release observations

Methods remain those in [measurements](../../measurements.md): sequential runs after all compilation/tests; warm filesystem caches; five warm-ups excluded; 30 process/task samples; 30,000 event deltas. Core timing excludes SDK/provider/registry construction; fresh ACP prompt includes lazy setup; warm prompts exclude session creation; first-delta timing includes local HTTP/SSE and ACP delivery. No timing measures a remote model, pure protocol overhead, forced-cache cold start or bare-metal ceiling.

C2 adds 276,608 bytes (2.22%). Both Linux builds exceed the provisional 10 MiB target; this observation remains visible for release sizing and does not become a new acceptance ceiling. Core/CLI medians increased while warm ACP decreased; fresh ACP was nearly unchanged. This single ordered comparison on a shared hosted VM cannot isolate the cause of those differences or establish universal performance equivalence. No runtime optimization or profile change was made to hide them. Unlike the earlier macOS sensitivity follow-up, this Linux run did not execute ten alternating event-process pairs. The checked-in aggregates retain p95/p99 and method limits; p99 over 30 samples is the observed maximum.

## Handoff

C2's selected single-agent capability slice and integration gates are complete. The broader alpha.1/0.1 release is not published or declared complete: packaging/distribution, doctor and stable extension ownership remain deferred, along with the explicitly scoped extensibility/interoperability capabilities and unsupported live hard-ceiling profiles. The [backlog](../backlog.md) now records the Linux sizing observation.

No checkpoint follows C2.5 in the current cycle. Select and specify the next cycle before implementation; OpenRouter is an eligible extensibility starting point. Reproduce this Linux proof by rerunning the linked workflow run, or dispatch the workflow once it is present on the default branch. Live provider verification remains separate and explicit.
