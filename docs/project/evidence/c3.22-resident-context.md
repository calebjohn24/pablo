# C3.22 partial — Shared retained context

Scoped roots now hold an atomic root-ledger reservation for retained model context.
The initial measure is the existing serialized instructions/history/tool-catalog
representation with opaque provider continuations substituted for their public
messages. Streamed text reserves its JSON-escaped byte growth before retention and
text delivery. Tool identity/argument growth uses a conservative escaping bound;
continuations reserve their encoded bytes. Tool output keeps its separate bounded
execution buffer and must fit shared context before being retained as history.
Repair feedback is similarly admitted before retention. Exact committed-history
measurements replace conservative stream estimates at subsequent generation
boundaries. This is an encoded model-context budget, not an RSS limit.

Children already reserve their complete context ceiling before starting. Their
local retained-growth meter now enforces that admitted ceiling without charging
the root ledger again. The root reservation remains held until its driver history
has dropped and child/tool cleanup has joined, then releases before RunFinished.
Child capacity remains owned by its existing dispatcher lease until its worker join.

An advisory capacity query excludes other agents' reservations and respects each
agent's ceiling. Compaction thresholds, candidate selection and continuation room
use this effective capacity; actual growth still requires atomic admission. A
summary request is covered before provider delivery while retaining the old
history reservation. A
successful compaction replaces history and reduces the reservation only after the
accepted compaction boundary. The summary prompt, protected task prefix, complete
recent turns, ownership and externally held child handles remain unchanged.
Unscoped calls omit the meter and extra retained-history serialization.

Behavioral verification includes a root whose initial history cannot fit alongside
an existing child (zero provider calls), child admission during root text streaming,
rejection of subsequent escaped text before it exceeds total context, and exact
root/child reservation release. Another test proves a child can stream inside its
already-full reservation without double charge while rejecting excess growth.
The five threshold/overflow compaction scenarios now also assert shared capacity
shrinks to the accepted replacement before the next model and releases at terminal;
their existing detail/prefix/recent-turn assertions remain in place.
