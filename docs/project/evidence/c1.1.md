## Result

The two-crate Cargo workspace builds a Rust library and executable. A host can stream a text run through the core with an injected OTel tracer and an inline event sink. The executable's offline demo drives the same lifecycle. [Runtime documentation](../../runtime.md) records the implemented contracts, bounds, telemetry mapping, and limits of this checkpoint.

The decisive integration fixture prevents its provider from completing until the host observes its first delta. It then checks the complete output, ordered events, one terminal outcome, provider request context, stream cleanup, and actual spans from the OTel SDK's in-memory exporter. Native JSONL and OTel share trace/span IDs, parentage, and exact start/end timestamps. Sampling-disabled and exporter-free fixtures also retain valid native identities.

## Additional behavior covered

- Ordered scripted chunks, UTF-8 byte bounds, missing usage/cache values, and independent session turns.
- Input, model-call, output-byte, output-token, event-count, and trace-byte exhaustion.
- Missing/duplicate stream finishes, text after finish, provider length finish, and transport failure without retries.
- Provider opening and streaming timeouts, dropped pending work, and closed lifecycle spans.
- Preservation of a provider failure's delivery certainty when a later trace write exhausts capacity.
- Native content opt-in, default redaction, content-free OTel spans, and no token events in OTel.
- Terminal space reservation, worst-case JSON escaping, and explicit reporting when I/O prevents terminal delivery.
- Invalid configuration before admission, metadata bounds, and failure before delivery recorded as not sent.
- The actual built executable, private trace permissions, exclusive file creation, explicit content capture, and unsupported CLI options.

The first compile exposed missing `Send + Sync + 'static` bounds on injected OTel spans and an incorrect assumption that `TraceFlags` implements Display. These were corrected using the SDK's required bounds and explicit two-digit hexadecimal flags. All subsequent compilation and test gates above passed. Review also improved first-failure preservation and sink-delivery certainty, with regression coverage.

## Scope and handoff

C1.1 is complete on this macOS host. The user's root `.env` was not read or changed; executable tests used separate synthetic credentials in temporary fixtures. No live provider, HTTP fixture, Collector, or Linux gate was run or claimed. The source brief is unchanged.

The current slice supports one text call. It does not yet implement tool registration/dispatch, explicit cancellation, ACP, incoming W3C context, full OTel environment configuration, or network export. Inline sink calls must return promptly; blocking sink I/O is outside the asynchronous deadline. I/O failure cannot guarantee delivery of a terminal record. These limits are documented, not silently advertised as complete release behavior.
