# C3.22 partial — Capacity, runtime accounting and mutation serialization

This advances C3.22; it does not pass A02 or enable delegation.

The root ledger now owns finite capacity leases for active/pending children,
processes, MCP sessions, aggregate context, queued input and retained results. There
is one active child at this checkpoint. Child process/MCP/context capacity requires
an active slot; root and per-child bounds intersect. Leases are non-cloneable and
release only their own contribution. Replacement checks the whole proposed state
before committing, so a queued child keeps its queue reservation when promotion
fails. The owner must join associated work before dropping its bookkeeping lease.

A cancellation/deadline-aware root mutex serializes native filesystem mutations.
Closing admission wakes queued mutation waiters. Scoped runtime fs.write/fs.edit
calls acquire the gate before tool admission and hold it through joined execution;
waiting cancellation does not spend tool allowance or touch a file. Shell and
external writers remain outside this gate and require host isolation.

`Runtime::with_root_ledger` now applies shared model/tool accounting at actual
runtime admission. It accepts an already admitted host scope, not child authority
or capacity selections. Local accounting is staged until shared admission succeeds,
preventing phantom charges on a rejected global reservation. Shared model tickets
settle after provider completion/cancellation using the same observed usage and
delivery certainty as local accounting. Fallback, compaction and repair use the
shared consume path. A shared root deadline prevents later runtimes from resetting
the root's clock. Per-run native accounting remains per-agent; aggregate terminal
rollups and agent attribution still await supervisor integration.

A shared tool rejection emits a finished tool span/result with `admission_failed`
and preserves the actual root limit in the terminal outcome. Closed/cancelled
admission remains cancellation; other shared setup failures use safe
`child_admission`, included in task/ACP failure schemas and OTel mapping.
