# C3.34 — Release documentation site

The user requested a release-oriented landing page, detailed GitHub documentation, Cloudflare Pages deployment and a browser-use visual review. This is a documentation and presentation slice of C3.34. Release archives, installation tooling and B01 acceptance remain held and incomplete.

## Published result

- Production: <https://pablo-runtime.pages.dev>
- Verified immutable deployment: <https://93672314.pablo-runtime.pages.dev>
- Sixteen guide pages live under `docs/guide/`; the VitePress build synchronizes those exact Markdown sources into the site so GitHub and deployed documentation share one source.
- The dark technical landing page includes a responsive terminal example, local search, mobile navigation, release status and direct routes into configuration and integration material.
- A GitHub Actions workflow builds pull requests and is ready to deploy `main` after the repository receives `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` secrets. The production deployment was also exercised directly with Wrangler.

## Resource comparison

The landing page places the resource comparison immediately after the hero and before the feature cards. The detailed benchmark page publishes exact values, method and limitations. Responsive SVG assets compare Pablo, Claude Code, Codex and Pi on peak process-tree RSS and median CPU utilization as a percentage of one core. CPU seconds remain a secondary table value rather than a primary chart metric.

The graphic uses the checked-in C3.33c pilot evidence. It covers six synthetic non-coding knowledge-work tasks on macOS arm64. The page identifies the single-seed, differing-model/provider/tool/reasoning and collection-time limitations; the comparison is exploratory rather than a causal or universal performance claim.

## Browser-use review

Browser-use exercised the landing page, getting-started, configuration and benchmark routes on desktop and 390-by-844 mobile viewports. It also opened mobile navigation, used local search to navigate to the ACP cancellation section, inspected image sources and checked document widths.

The review found and fixed:

- desktop hero artwork overlapping the main heading at wide viewports;
- the terminal example falling outside the mobile viewport;
- a large orange heading permalink appearing before a landing-page section title;
- the benchmark table widening the complete mobile document;
- public TOML example links being intercepted as site routes instead of returning raw files.

The final production check showed zero horizontal document overflow at 390 pixels, selected the dedicated vertical benchmark graphic, displayed the CPU-utilization column in the benchmark table and kept the landing-page heading permalink hidden. The desktop comparison renders the two panels side by side with readable labels.
