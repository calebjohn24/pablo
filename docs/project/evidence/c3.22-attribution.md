# C3.22 partial — Ledger-derived execution attribution

Each registered agent binds once to a native execution before its run span starts.
The ledger supplies immutable root, parent, kind and depth; the executing session
is validated and then fixed. Unknown agents, duplicate bindings and mismatched root
sessions fail before provider/tool admission. Root run/session IDs agree with the
ledger; children have independent native run IDs and their source ACP session.
Decoded identity projections grant no AgentRef or registration authority.

Scoped native events, including metadata-only JSONL, retain the same `agent`
projection. ACP correlation and terminal metadata project it without changing
ownership. All five runtime span creation paths (run, model, tool, validation and
compaction) attach identity attributes before starting the span. Existing causal
parenting is preserved. Unscoped events omit the optional object. ACP's native
frame estimate includes worst-case escaped identity bytes and uses exact bounded
serialization when other optional metadata is present.
