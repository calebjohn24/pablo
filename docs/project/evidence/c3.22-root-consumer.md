# C3.22 follow-up — Root sequence and shared native consumer

TreeSink claims a single root consumer before execution or child registration. Its
clones serialize root/child delivery under one delivery mutex, separate from the
admission ledger mutex. Every accepted source must match a previously bound agent,
root, session and native run. The sink assigns optional root_seq, preserving the
original per-agent seq, timestamps, span IDs, metadata and content. Already
projected or foreign records and a second consumer claim are rejected. Child
records can be moved into the sink without copying their content. Root terminal
success closes the shared sink; child terminals keep it open.

Shared trace admission reserves the maximum encoded width of the additional
root_seq field before delivery. Charges therefore conservatively bound actual
writer bytes. Records do not spend event or trace admission again at the consumer.
The immutable projection mode is checked again when committing admission so a
configuration race cannot silently undercharge. Untraced trees still skip JSONL
size measurement. Metadata-only JSONL retains root_seq. ACP correlation and its
schema expose the final root sequence in a coalesced projection while retaining
per-agent seq_start/seq_end. The native record size guard includes the extra field.

Supervisor::consume_updates drains the existing bounded native update channel
into this shared sink and acknowledges successful consumption. It adds no worker
or unbounded queue. The host must join this consumer alongside its root run.
Sink failure closes the receiver and cancels the root, waking supervision and
joining admitted child work. A producer receipt retired during cancellation does
not invalidate a record already delivered successfully.

Two core regressions verify concurrent root/child writers, unchanged original
records, one monotonically increasing root sequence, foreign source/duplicate
consumer rejection, trace exhaustion with protected terminals in both capture
modes, bounded actual writer bytes and no double charge. The real supervised child
fixture now uses the actual consumer and checks its seven native lifecycle/delta
records and sequences. Another supervisor regression makes the sink fail and
proves root cancellation plus settled/joined children with released active/queued
capacity. ACP coalescing retains the correct final root sequence.
