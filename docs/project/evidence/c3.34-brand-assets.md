# C3.34 — Brand assets and Pages URL

The user requested a favicon, Open Graph image and a shorter Cloudflare Pages URL for the release documentation. This follow-up remains a documentation and presentation slice of C3.34; it does not resume the held archive and installation work.

## Result

- Cloudflare already served an unrelated site at `pablo.pages.dev`, so that global subdomain could not represent this project.
- The available `runpablo` Pages project was created and the site was deployed to <https://runpablo.pages.dev>.
- The site configuration, sitemap, README, copy-ready example links, Wrangler project and GitHub workflow now use `runpablo.pages.dev` or the `runpablo` project name.
- `website/public/favicon.svg` defines a compact orange Pablo monogram on the existing dark surface. A rendered 180-by-180 Apple touch icon accompanies it.
- `website/public/og.svg` retains the editable vector source for the dark technical social card. `website/public/og.png` is its visually reviewed 1200-by-630 raster output.
- Open Graph, Twitter card, favicon and Apple touch metadata point to the new production URL and include explicit image dimensions and alt text.
- GitHub Actions now contains the `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` secret names required by the workflow. Their values were sent directly to GitHub CLI through stdin and were not written to repository files or project records.

## Verification

- `cd website && npm test` passed the production build and five site tests. The asset test verifies favicon/touch-icon output, exact 1200-by-630 PNG dimensions and the `runpablo.pages.dev` social-image metadata.
- `cd website && npm run deploy` created the first production deployment at `runpablo.pages.dev`; Wrangler returned immutable deployment <https://7675f44d.runpablo.pages.dev>.
- Browser-use opened the production alias at a 1728-by-1117 viewport and confirmed the expected landing page.
- Browser evaluation found the production favicon, Apple touch icon, Open Graph URL, 1200-by-630 image metadata and Twitter image at `runpablo.pages.dev`.
- HTTP checks returned `200` with `image/svg+xml` for the favicon and `image/png` for the touch icon. The downloaded production Open Graph PNG matched the checked-in 1200-by-630 PNG byte for byte.
- `gh secret list --repo calebjohn24/pablo` showed both required Cloudflare Actions secret names. Secret values were not read back.
- `node scripts/project.mjs check` and `git diff --check` passed after the records were updated.

The original `pablo-runtime.pages.dev` project remains as an earlier deployment, while every current public and deployment reference selects `runpablo.pages.dev`. The first workflow run from `main` will validate the newly configured GitHub secrets in Actions.

Use <https://runpablo.pages.dev> as the public documentation URL. Review the favicon and social card sources with the rest of the site change. C3.34 remains blocked by the standing packaging hold; C3.34b remains the next ready implementation checkpoint.
