# C3.36 embedder getting-started documentation

Date: 2026-09-14

## Scope

The public guide and repository README now begin from an application developer's integration decision. The getting-started path installs and verifies Pablo before introducing a provider request, then leads the reader through either an ACP child process or direct Rust embedding. CLI JSON remains available for evaluation, jobs and scripts.

The guide makes the current release boundary explicit: the installer is available for inspection, while source installation remains the working path until the four `v0.0.1` archives pass native acceptance and are published. It also explains exact-version upgrades, source-install replacement, host-owned workspaces, credentials, sandboxing, tool authority, output validation and observability.

The ACP page and TypeScript reference client accept an installed executable through `PABLO_BINARY`. The Rust page gives an exact-revision Git dependency pattern for the prerelease and explains when a host should choose the core instead of ACP. Landing-page calls to action and site navigation now lead to the integration chooser.
