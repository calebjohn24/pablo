## Public installation proof

The exact advertised command passed on an Apple silicon Mac using a fresh absolute temporary home and a minimal system `PATH`:

```sh
curl -fsSL https://runpablo.pages.dev/install.sh | sh
```

The installer selected `aarch64-apple-darwin`, wrote `$HOME/.local/bin/pablo`, and produced the expected frozen binary SHA-256 `a35c0ff8be1b3fce3a62f8095899eb019b77130e23acb7e4af9bedcd0716fd68`. The binary reported `pablo 0.0.1`, its offline demo printed `Hello from pablo.`, and piped `--remove` deleted the owned binary and receipt. The smoke did not touch an existing user installation.

A second fresh unprivileged E2B Debian 12 x86_64 sandbox installed through the same public command. Its binary matched `b31d3674cedec9dc0f99d3058570754bd253528d66171cc8737862453391070a`, reported `pablo 0.0.1`, ran the offline demo, and was removed through the live script. The sandbox was killed, and the post-run listing found no matching running or paused sandbox.
