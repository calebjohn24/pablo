# C3.26 — R01 Agent Cards and bounded wire contracts

R01 passes for the configured A2A client admission and wire contract. Production supervised task transport, SSE framing/timer enforcement and assembled artifacts remain C3.27; adverse cancellation and Collector propagation remain C3.28. No remote execution tool or server listener is claimed here.

| Acceptance | Implementation and observed proof |
| --- | --- |
| Allowlisted card resolves to an untrusted remote proxy with separate identities | `ResolvedDeployment::resolve_a2a`, core card/proxy modules and `a2a_cards` tests retrieve the independent SDK card under host ceilings. Fresh local `remote_a2a` identities retain the card digest, protocol and endpoint; remote context/task IDs bind separately and cannot replace local sessions. Root-ledger kind checks reject forged projections. |
| Pin binding and freeze bounded message/task/artifact/cancel mappings | [Contract](../contracts/c3-a2a.md) and pinned SDK-generated vectors select A2A 1.0 JSONRPC/HTTP/SSE. `a2a_wire` tests round-trip immediate Message, terminal Task, streamed status/artifact/task, canceled Task and errors against the independent SDK dispatcher. Unsupported versions reject before its handler. Byte/count/union/identity failures reject locally; execution timers are frozen requirements for C3.27. |
| Host controls credentials, input and authority | Card GETs carry no credentials and follow no redirects. Exact configured RPC endpoints scope bearer resolution; authority intersections reject unknown names and broader endpoints/credentials. Card metadata grants no local tools, Skills, policy or input. SDK fixtures observe only explicit synthetic selected input and zero history. |
| Required content and optional correlation | Text, structured data including null, inline files and inert URL Parts pass independent SDK round trips. File-only/data-only card modes work. Selected input is limited to 32 KiB, inline bytes decode within the same bound, and filenames/URLs cause no filesystem or network operations. Negotiated trace metadata/headers validate a closed bounded profile; generic peers omit it. Decoding preserves the ambient OTel parent. Unknown optional extensions remain interoperable; unsupported required card extensions reject. |
