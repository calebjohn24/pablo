# C3.36 application-facing subagent guide

Date: 2026-09-14

## Scope

A dedicated public Subagents guide now explains when application hosts should delegate, how to enable supervised local children, the `spawn`/`inspect`/`wait`/`stop` lifecycle, capability narrowing, shared root budgets, validated handoffs, remote A2A delegation, observability and current release limits.

The guide is linked from getting started, the integration sidebar, the extensibility guide and the README integration matrix. It uses “subagents” as the reader-facing term and explains that configuration and runtime records call local subagents “supervised children.”

The content stays inside the implemented release boundary: temporary depth-one local children, two active children and sixteen total children per root, typed in-memory ACP dispatch, host-configured remote A2A peers, explicit validated handoffs and no persistent/external ACP children or A2A server.
